# ⚡ חשבון חשמל לרכב — Energy Payment

אפליקציה לאנדרואיד ו‑iPhone למעקב וחישוב תשלום חשבון חשמל לטעינת רכב חשמלי.

נבנתה עם **React Native + Expo + TypeScript** — קוד אחד שרץ על שתי הפלטפורמות.

## ✨ יכולות

- **קליטת קריאת מונה** וחישוב אוטומטי לפי הנוסחה:
  `( קריאה נוכחית − קריאה קודמת ) × 0.68 = חשבון`
- **מילוי אוטומטי** של הקריאה הקודמת מתוך החשבון האחרון.
- **מעקב היסטוריה** של כל החשבונות האחרונים, כולל תאריך, צריכה וסכום.
- **תצוגה ויזואלית** של פירוט החשבון (כמו "פתק" מוכן לשליחה).
- **כפתור העתקה** שמעתיק ללוח את הטקסט בפורמט הבא:

  ```
  <שם משתמש> — פרוט חשבון חשמל

  תשלום חשבון מונה עבור <כתובת>

  קריאה קודמת - x
  קריאה נוכחית - y

  סהכ הועברו z שקלים
  ```
- **הגדרות אישיות**: שם משתמש, כתובת מונה ותעריף ניתן לעריכה (ברירת מחדל 0.68 ₪).
- כל הנתונים נשמרים מקומית במכשיר (AsyncStorage) — ללא שרת וללא אינטרנט.

## 🚀 הרצה

דרושים Node.js ו‑npm.

```bash
# התקנת תלויות
npm install

# הפעלת שרת הפיתוח
npm start
```

לאחר ההפעלה:

- **iPhone**: סרקו את ה‑QR עם אפליקציית **Expo Go** (מ‑App Store) או המצלמה.
- **אנדרואיד**: סרקו את ה‑QR מתוך אפליקציית **Expo Go** (מ‑Google Play).
- או הריצו `npm run android` / `npm run ios` עם אמולטור/סימולטור.

## 📦 בנייה לחנויות (build)

לבנייה של קבצי התקנה (APK/AAB ל‑Android, IPA ל‑iOS) משתמשים ב‑[EAS Build](https://docs.expo.dev/build/introduction/):

```bash
npm install -g eas-cli
eas build --platform android
eas build --platform ios
```

## 🗂 מבנה הפרויקט

```

  storage.ts                 # שמירה/טעינה מקומית (AsyncStorage)
  theme.ts                   # ערכת צבעים וסגנונות
  components/
    BillPreview.tsx          # תצוגה ויזואלית + כפתור העתקה
  screens/
    CalculatorScreen.tsx     # מסך חישוב חשבון
    HistoryScreen.tsx        # מסך מעקב היסטוריה
    SettingsScreen.tsx       # מסך הגדרות
```
